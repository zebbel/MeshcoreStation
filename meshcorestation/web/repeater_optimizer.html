Hop-limit recommendations

Experimental suggestions can be displayed only with a sufficiently complete observation period, a selected role, recent neighbor information and manually read current settings. They are not guaranteed delivery-safe values.

Each write requires confirmation in Repeater Management, a fresh value check, and readback verification. No automatic configuration changes.

Neighbor snapshots

One stored snapshot contains at most 15 reported neighbors. Missing entries do not prove lost links. Scheduled sampling never loads extra pages.

Storage and retention

Detailed packets are stored for 60 days by default, daily aggregates for 365 days, neighbors for 90 days. Limits may shorten detailed history to protect the Pi SD card.

Verified changes and before/after

Compares equal 24-hour samples before and after a verified change, with a one-hour settling gap, if the legacy selected-repeater measurements cover both windows. These are descriptive and cannot prove improved reachability.
