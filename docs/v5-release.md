# MeshcoreStation 5.9.2 — Dashboard Branch Switching

The dashboard updater now lists V5 and V6. Install this patch on your
current branch first. Then open **Settings → Updates / version**, select
`V6`, click **Check for updates**, and confirm the switch.

Both branches use the same database format. The updater uses the existing
backup and rollback procedure and checks the current branch on page load.
