# MeshcoreStation 6.0.0 — Multilingual Dashboard

- English and German are available under **MeshcoreStation Settings → Language / Sprache**. English is the default.
- The language is saved per browser and applies to dashboard controls, charts, maps, dialogs, and Room Server administration.
- Missing translations fall back to English. Device responses, saved messages, names, and configured bot replies retain their original values.
- V6 uses the existing V5 database format. Dashboard updates stay on the V6 branch.

See the [dashboard language documentation](v6-localization.md) for setup and catalog details.
